# 月色海风主题

自定义 Hexo 主题，首页使用暮海背景与玫瑰窗台明信片。文章与归档由 Hexo 自动生成。

- 首页大标题、短句、签名：编辑本目录 `_config.yml`。
- 背景：`source/images/harbor-dusk.png`。
- 明信片与文章默认缩略图：`source/images/rose-postcard.png`。
- 网站名称与作者：编辑博客根目录 `_config.yml`。
- 桌宠：博客根目录 `source/pet/`，移动端首次访问默认收起，点击“召唤拉菲”展开。

两张环境插画由内置 ImageGen 生成，未使用人物参考图。桌宠使用已注明出处的原始 Q 版 PNG；待机与点击动作由网页实现。
