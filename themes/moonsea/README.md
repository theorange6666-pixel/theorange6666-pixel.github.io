# 晴天野餐主题（基于 moonsea）

2026-10-20 按用户提供的小狗野餐插画更新为天空蓝、草地绿、奶白与浅粉配色。主题目录仍为 moonsea，文章与归档由 Hexo 自动生成。

- 首页短句、签名：编辑本目录 `_config.yml`。首页时间组件按访客设备时区显示时间、日期与星期，每秒更新；实现在 `source/js/moonsea.js`。
- 首页主图与文章默认缩略图：`source/images/picnic-day.png`（用户提供，1672 × 941）。
- 桌面标题覆盖天空留白；760px 及以下文字与完整插画上下排列，不裁切人物。
- 原暮海背景与玫瑰明信片仍保存在 images 目录，当前页面不再引用。
- 网站名称与作者：编辑博客根目录 `_config.yml`。
- 桌宠：博客根目录 `source/pet/`，移动端首次访问默认收起，点击“召唤拉菲”展开。
- 键盘彩蛋：页面上依次输入 `love`（不区分大小写，相邻字符间隔不超过 3 秒），粉色爱心上浮约 3 秒。输入框、编辑区域、组合键与输入法组合期间不触发；动画期间不会叠加，结束自动清理，减少动态效果模式只显示少量淡入淡出的爱心。

桌宠使用已注明出处的原始 Q 版 PNG；待机与点击动作由网页实现。文章、站点作者及发布配置未改动。
